# Advanced Banking System

Advanced Banking System developed using Object-Oriented Programming (OOP) principles in C++.

## About The Project

This project is an enhanced version of a previous banking system, completely redesigned using a fully object-oriented architecture to improve maintainability, scalability, security, and code organization. The system includes encrypted passwords, login tracking, transaction logging, user management, permission-based access control, and robust input validation.

## Key Features

- Client account management.
- User management system.
- Deposit and withdrawal operations.
- Money transfers between accounts.
- Transaction tracking and logging.
- Transfer history tracking and auditing.
- Login history tracking and auditing.
- Password encryption for enhanced security.
- User authentication and permission-based access control.
- Robust input validation system to prevent invalid data entry.
- Improved error handling and exception management.
- Modular and reusable class-based design.
- File-based data persistence.

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes
- Encapsulation
- Abstraction
- Inheritance
- File Handling

## Project Goals

This project demonstrates the practical application of software engineering principles, object-oriented design, security practices, and data validation techniques in building a secure, reliable, and scalable banking management system.
